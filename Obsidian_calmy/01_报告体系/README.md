# 01 报告体系

本模块定义 Calmy 如何把生活材料转化为阶段性正式认识。

当前对齐：报告首先呈现问题怎样变化、最小必要知识怎样被使用、现实返回什么证据以及是否已经足够；学习时长、课程完成和自律感只能作为可选背景，不能单独成为结论。

## 内容

- [[01_自我世界关系报告]]：周期性 Word 文档的定位、结构与长期价值。
- [[02_个人实验报告]]：把问题、假设、现实反馈、分析和下一轮实验组织成正式报告。

## 与其他模块的关系

- 从 LIMS 与 ELN 获取样品、结果、观察、偏差和调查材料。
- 从产品体验模块获得一页报告与完整报告的分层展示方式。
- 报告中的 Meaning 和 Conclusion 必须由人确认。
