# 04 可配置平台

本模块定义 Calmy 如何从固定功能软件发展为可配置生活信息平台。

当前对齐：平台允许用户配置学习相关变量，但系统默认模板仍以问题、应用证据和停止条件为核心，不预置“每日学习”或自律评分。

## 内容

- [[01_自定义体系]]：对象、检测项目、标准、流程、展示、模板、继承和组件组合。
- [[02_模块与权限]]：模块定义、角色模板、权限层级、流程权限和多成员空间。

## 核心约束

- 强自定义主要发生在设计阶段，日常使用尽量零配置。
- 所有高级能力必须有可直接使用的默认模板。
- 角色模板负责常见权限，局部覆盖负责例外。
- 系统由 Object、Module、Workflow、Permission 等元对象组合，而不是依赖写死模块。
