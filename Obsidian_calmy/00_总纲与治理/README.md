# 00 总纲与治理

本目录维护总文档的前言、目录和全库治理规则。

## 权威顺序

1. 根目录总文档
2. 已同步的模块正文
3. 各模块 README
4. 草稿、讨论和实现记录

以上顺序只适用于 `Obsidian_calmy` 文档库内部。跨仓库的产品执行权威依次是 `docs/product/PRODUCT_DECISIONS_2026-08-19.md`、`docs/product/CALMY_UNIFIED_PRODUCT_DESIGN_2026-08-29.md`、本思想母本与模块正文。

当下级文档与上级定义冲突时，不允许各自长期存在两个版本。应通过双向同步或一次明确的设计决策消除冲突，并保留变更原因。

## 总文档职责

- 定义 Calmy 的产品定位和核心原则。
- 保存全部正式产品设计内容。
- 作为模块拆分、评审和实现验收的共同依据。
- 保留产品认识的演化轨迹，而不是只保留最新结论。
