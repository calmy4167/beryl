# 05 软件之外的产品设计

本模块把 Calmy 从软件扩展为连接人、现实空间、纸张、关系、仪式和长期档案的生活基础设施。

当前对齐：所有媒介都围绕现实问题、下一次实践和反馈设计；学习实验卡统一改为问题实验卡，不制造学习身份、固定时长或打卡仪式。

模块正文：[[01_生活基础设施与服务设计]]

## 核心约束

- 入口优先围绕现实对象、事情和问题，而不是软件模块。
- Measurement、Observation 和 Meaning 具有同等地位。
- 支持证据等级、反证、标准生命周期、无结论和认识成熟度。
- 支持纸质报告、实验卡、年度档案、零设备状态和有价值的遗忘。
- 关系不是简单的数据共享；“我的、你的、我们的”应被分别建模。
