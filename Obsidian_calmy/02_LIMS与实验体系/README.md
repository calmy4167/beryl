# 02 LIMS 与实验体系

本模块定义 Calmy 借鉴真实实验室、LIMS、ELN 和 QMS 的结构方式。

当前对齐：LIMS 用来检验处理真实问题的方案，不用来给人做自律质检。过程时长只有在用户选择、外部标准要求或实验假设明确涉及它时才进入规格。

## 内容

- [[01_真实LIMS与实验过程映射]]：真实实验流程与个人系统的逐层映射。
- [[02_样品测试规格限值与批次]]：Sample、Test、Requirement、Specification、Limit、Result、Batch、OOS、OOT 等核心模型。

## 核心约束

- 样品是检测项目的载体，不把单个结果误当成样品。
- 要求属于标准，限值属于规格，结果属于测试，测试属于样品，样品属于批次或任务。
- 检测报告与实验报告承担不同职责，不应混为一个文档。
