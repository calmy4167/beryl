# Calmy 当前 UI 与交互审查 · 2026-10-13

建议方向：白色完整工作区、112px 窄玻璃导航、稳定的页面头与操作区、按需出现的详情。保留已认可的苹果质感，将下一轮重点放在功能层级、可读性和操作一致性。

## 审查范围与证据边界

- A 独立查看当前开发预览的今天、记录、任务、处境、回顾以及导航浮层。1280×720，paper 主题，侧栏实测112px，主壳x=16/width=1248，已加载最新 calmy-image2-ui.css。
- B 独立扫描 src/vue 并审查键盘、焦点、浮层与响应式代码。A完成设计判断后才汇合B结果。
- 预览导航跳转生产 /app 路由会要求登录；不能当作生产导航故障。非 Today 预览路径未命中部分 /app 专属样式，预览左缘遮挡不判为正式页面缺陷。
- 真实数据详情、保存/撤销、手机布局和读屏尚未完成运行时验证。评分是当前空态与源码的初步评估。
- 本轮没有修改业务代码、前端代码或用户数据；没有安装依赖。

## 已有优势与产品适配

浅白内容区与玻璃侧栏已经适合短时整理思绪的使用场景。记录页“记下来，不用现在决定。”降低进入压力；处境页的可选字段已有渐进展开。现有加载、错误、重试、命令面板，以及桌面的最近记录抽屉和撤销提示值得保留。

目前最主要的偏差在信息层级：PRODUCT.md强调今天、记录、处境、回顾四条主线，而界面先呈现九个功能分组；首页的大标题、多处空态和零值统计又共同强调“没有内容”。下一轮需要让开始行动更容易、扩展功能更容易找到。

## 优先问题

### P1：主要按钮白字白底

现场确认回顾“保存复盘”的前景与背景均为 rgb(255,255,255)，opacity=1；处境“新增处境”也只有轮廓。原因是 [统一按钮规则](/D:/dsharness/src/styles/liubai/calmy-image2-ui.css:680) 将 .chip 背景覆盖为白色，但 [原主按钮规则](/D:/dsharness/src/styles/liubai/liubai-v11.css:397) 保留白色文字。对应 [新增处境](/D:/dsharness/src/vue/pages/LiubaiMatters.vue:186)、[保存复盘](/D:/dsharness/src/vue/pages/LiubaiReview.vue:195)。

应建立主按钮、次按钮、轻按钮、危险按钮和禁用态的完整规则；普通样式不能覆盖主按钮状态。先处理可识别性，再调整材质。建议工具：/impeccable harden。

### P1：常用主线隐藏在九个分组中

当前112px侧栏显示九组，常用入口需要先展开；“常用入口”换行，更多分组需要滚动。浮层约224px宽，会覆盖部分标题和内容。源码见 [侧栏结构](/D:/dsharness/src/vue/shell/LiubaiShell.vue:747)。

建议保留112px宽度，让今天、记录、处境、回顾常驻；其余能力通过“全部模块”继续访问，桌面入口可保留在品牌/首页位置。底部固定搜索、设置。收起浮层后主栏仍显示当前页状态。建议工具：/impeccable shape。

### P2：空态、统计与大标题竞争注意力

[今天页](/D:/dsharness/src/vue/pages/LiubaiToday.vue:107) 的大标题、当日重点、四项统计、记录空态重复表达空缺。标题上限52px，重点容器最小高210px；当前任务空态也有明显的大块留白。

建议固定页面身份标题“今天”，将空态放进内容区；提供清楚的输入与添加按钮。重点列表优先，最近记录次之，统计收成一行摘要或可展开区域。页面外壳铺满可用空间，空容器按内容自然取高。建议工具：/impeccable distill。

### P2：动作语义与键盘路径不一致

[今天](/D:/dsharness/src/vue/pages/LiubaiToday.vue:129) 点击任务标题直接设为重点，缺少等价键盘入口；完成控件是span且只处理Enter；新增依赖Enter。任务中的“×”表示取消，处境中表示归档。中文输入提交未见composition保护，需真实输入法确认。

[全局快捷键](/D:/dsharness/src/vue/shell/LiubaiShell.vue:455) 没排除SELECT，数字键可能在选项操作中切换模块；设置和命令面板缺少统一焦点陷阱与回焦；[日期菜单](/D:/dsharness/src/vue/liubai/LbDateNav.vue:34) 缺少底部翻转与完整菜单键盘操作。以上除明确现场观察外均为源码证据。

建议始终有可见“添加/记录”按钮；查看、设重点、完成各有清楚入口。统一弹层打开聚焦、Tab范围、Esc关闭与回焦。单字符快捷键避开表单和组合输入状态。建议工具：/impeccable harden。

### P2：回顾表单的进入负担和禁用原因不明确

[回顾页](/D:/dsharness/src/vue/pages/LiubaiReview.vue:160) 优先展示专注图表，随后一次展开五个文本框；无plan时仍可编辑，但保存禁用且缺少相邻解释。

建议优先展开两个核心反思字段，其余三个置于“补充思考”，保留全部字段及业务语义；统计成为参考区。保存旁明确显示可保存、保存中、已保存、失败或前置条件。建议工具：/impeccable clarify。

## 建议的页面设计

| 页面 | 内容结构 | 主要交互 |
|---|---|---|
| 外壳 | 112px窄栏；统一页面头；白色完整工作区 | 四条日常主线直达，扩展功能从全部模块打开 |
| 今天 | 日期/标题、快捷输入、重点清单、最近记录、次级统计 | 明确添加按钮，重点和完成动作分开 |
| 记录 | 输入区、记录时间线、按需处理区 | 先记录，选中后显示关联/整理动作 |
| 处境 | 搜索筛选、新增、简洁列表、右侧详情 | 浏览列表保持位置，复杂字段在详情展开 |
| 任务/看板 | 一条紧凑工具栏、视图切换、列表或列 | 新增位置固定，数据源和筛选不各占大面板 |
| 回顾 | 核心反思、可选补充、参考记录/统计、保存状态 | 解释禁用原因，长内容阅读区控制行宽 |
| 桌面 | 单输入主场景、最近记录抽屉 | 与今天/记录明确分工，减少重复入口 |

建议视觉参数用于下一版设计验证：页面标题24–28px、正文14–16px、桌面控件36–40px、行高44px、间距8/12/16/24/32px、卡片圆角12–14px。侧栏文字不要为塞入更多项目继续缩小。移动端采用覆盖抽屉和更大触达区域。主列表可扩展至整片内容区，长文/编辑区限制阅读宽度或辅以详情列。
