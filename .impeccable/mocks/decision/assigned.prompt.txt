Use case: ui-mockup
Asset type: high-fidelity desktop web application direction comp, 1440x900 landscape
Primary request: Design the CALMY personal reflection workspace in the committed visual world “澄明光桌 / Clarity Light Table”. This is an operating product UI, not a landing page, poster, analytics dashboard, or illustration. The visitor arrives mentally overloaded, identifies one real-world priority, writes the first step, optionally records a note, then leaves.
Input images: attached screenshots are style and craft references only. Borrow their mature SaaS proportions, soft high-key surfaces, precise spacing, restrained accents, and polished finish. Do not copy their content, avatars, charts, card grids, finance data, or specific navigation.
Structure: A complete 1440x900 first viewport. The application sits lightly on a very pale cool blue-gray field without a heavy outer frame. One slim, single-layer left sidebar about 190px wide; no dark rail, no dual sidebar. Brand CALMY at top. Main links 今天 (selected), 记录, 处境, 回顾; a quiet 功能 disclosure below; settings at bottom. A thin top utility line in the content area with date, small search affordance, and a local/Feishu connection status; no profile avatar.
Main surface: one large continuous luminous work plane, not a grid of cards. Page heading 今天 and small sentence “抓住此刻最重要的事，然后回到现实。” The dominant object is a wide translucent focus sheet occupying the upper-middle area, titled “此刻最重要的事情”, showing one realistic Chinese example sentence and a single action “写下第一步”. Below it, 快速记录 is a compact horizontal composer, and 今天的记录 is an open three-row list integrated into the same plane. A narrow right-edge translucent index layer contains only four small shortcuts: 身体状态, 思考, 轨迹, 主动放下. No charts, KPIs, decorative metrics, avatars, illustrations, nested cards, or large empty marketing hero.
Visual world: a conservation light table translated into software. Optical white and cool mist-blue ground, frosted glass, translucent vellum sheets, subtle anodized-aluminum edges, precise 1px lines. Graphite ink. Cobalt blue is reserved for current selection/action, coral for one urgent state, aqua for a reflective state, amber for one note marker. Colors have fixed semantic jobs, never scattered decorative tiles. Large calm typography with strong Chinese legibility; no serif. Surfaces layer through slight translucency and fine edge highlights, not big drop shadows. The central focus sheet appears gently illuminated from beneath while surrounding layers recede.
Composition: asymmetric but balanced, dense enough to feel like a real product. Strong alignment, generous negative space, no repeated equal-width modules. Show the subject doing its job: the main priority and first step must be readable.
Text (verbatim): “CALMY”, “今天”, “记录”, “处境”, “回顾”, “功能”, “抓住此刻最重要的事，然后回到现实。”, “此刻最重要的事情”, “写下第一步”, “快速记录”, “今天的记录”, “身体状态”, “思考”, “轨迹”, “主动放下”.
Constraints: production-ready interface concept; orthographic straight-on screenshot; crisp legible Chinese; consistent component system; one viewport only.
Avoid: dark icon rail, dual navigation, bento grid, dashboard widgets, charts, KPI cards, gradients as decoration, purple AI glow, glassmorphism everywhere, generic rounded white-card pile, profile avatar, fake statistics, excessive icons, oversized radius, poster-like composition, watermark.
