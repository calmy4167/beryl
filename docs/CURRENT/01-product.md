# 当前产品假设

> 状态：探索中的方向基线，2026-10-05。本文摘要用于快速对齐；详细表达见[当前产品设计原文](../product/CALMY_PRODUCT_DESIGN_2026-09-19.md)及决策 D-018。

Calmy 当前探索的方向是帮助人理解自己正在面对的现实、作出选择，并在之后回看选择与现实反馈之间的关系。它不预设所有日常内容都要变成项目或任务，也不替用户作决定。

方向仍未通过完整真实场景和真实用户验证。现有 Today、Capture、Matters、Review、Future 等页面及 Action、Record 等对象，只说明代码中已有这些能力；它们不构成未来产品必须保留的导航或业务模型。前端布局和领域流程都可以基于验证结果调整。

雏形阶段以一条可运行、可持久保存、可导出的真实场景纵向流程作为学习工具。先观察用户能否理解和完成这个流程，再决定扩展页面、模型、协作、自动化或外部集成。

本文不覆盖的数据、安全和兼容底线见[硬约束](05-boundaries.md)。
