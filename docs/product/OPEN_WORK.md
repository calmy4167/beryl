## P0：发布前必须完成

### OW-02 核心页面的 Application Use Case 收口

扩展页面的直接同步写入已收口：Graph、Posts、Diary、Goals、Habits、Finance、Pomo、Inbox 的集合/标量/课题关联/旧版转换写入均已接入异步 Repository 与统一保存状态协议。剩余工作是把 Inbox 转换、Finance 关联等跨仓储流程继续提取为 Application Use Case，并补齐幂等键与重复提交测试，避免页面层直接编排事务。

验收：页面不直接编排跨仓储事务；本地已保存、等待同步、失败和冲突状态可区分；重复提交具有幂等结果。

### OW-03 IndexedDB 权威边界深化

完成剩余兼容查询、共享协作、历史回放和高级同步路径的持久化边界复核；明确 localStorage 只作为兼容回退，不再成为新的写入事实源。

验收：刷新、离线重开、存储失败、并发 revision 冲突和备份/迁移前 pending writes 均有可复现测试。

### OW-04 人工端侧与辅助技术验收

在真实移动设备、键盘、屏幕阅读器和大字号环境中复核核心四页、双侧栏、移动 More 抽屉、表单输入、保存状态、Focus/弹层关闭和错误恢复。自动化 smoke 已通过，但不能替代人工审计。

验收：无 P0 可访问性或数据丢失问题；320px、200% 缩放和系统大字号不丢失主行动与退出入口。

## P1：核心闭环稳定后的工程收口

### OW-06 Vue 兼容层退出评估

`src/main.ts`、`src/App.vue`、`src/router`、`src/views`、Vue Router 和 Element Plus 当前属于迁移兼容层；只有在依赖扫描、真实路由回归和回滚方案完成后，才分批删除。React 入口和 React 页面当前是生产主路径。

验收：所有生产路由、登录、设置、导入导出、同步和边缘模块均无 Vue 运行时依赖；删除每批兼容代码后全量测试与构建通过。

### OW-07 页面与领域编排拆分

继续拆分大型 `src/react/App.tsx` 和页面文件，将路由、壳层、页面状态、展示组件和 Application Use Case 分离；同时评估扩展模块的按需样式/资源拆分，不改变领域模型和现有 URL。

验收：页面职责可单独测试；跨页面行为通过用例或共享协议复用；切换模块不重复挂载无关监听器；核心首屏不因扩展模块样式和组件 eager 加载而膨胀。

### OW-08 扩展模块质量回归

为 Inbox、Tasks、Habits、Finance、Goals、Pomo、Diary、Posts、Library、Calendar、People、Graph、Scene 和 Admin 补齐离线、导入导出、同步、错误、空状态和可访问性回归，并明确哪些模块仍是兼容/实验能力。

验收：扩展模块不会破坏核心四页，不产生重复实体或第二套同步状态；实验能力不会误显示为稳定能力。

### OW-09 品牌与存储键长期迁移

制定 `beryl-*` 存储键、事件名、包名和用户可见文案的兼容读取与渐进迁移方案。禁止直接改名导致旧用户数据丢失；迁移完成前保留兼容读取和可验证回滚。

### OW-10 真实试点与指标验证

组织 8–12 位目标用户进行 2–4 周试用，观察首次价值时间、7 日闭环率、主动降载/暂停、数据恢复信任和系统是否增加压力。不得以页面数量、在线时长、浏览数量或连续使用代替产品价值。

## P2：受控扩展能力

### OW-11 Flow / 沉浸流实现

Flow 目前已完成产品、UX、路线图和验收设计，但尚未作为完整内容能力实现。按路线图分阶段实现：统一 Seed 与来源链路 → 有限浏览层 → Focus → 漫游/学习/回响/专题 → 收下/再见/学会/行动/关联 → 可解释推荐和偏好设置。

验收标准详见 `ROADMAP_AND_ACCEPTANCE_2026-08-22.md` 的 Flow 章节；不得先做无限滚动、自动播放、连续奖励或独立同步协议。

### OW-12 AI 理解层深化

真实 AI provider/offline model、知识网络和更深的建议能力暂缓。先保持本地规则 suggestion、证据、用户确认、可撤销和 Domain Command 边界，核心闭环试点证明价值后再扩展。

### OW-13 Obsidian Companion Bridge 真实联调

协议、Local REST 适配和浏览器 Vault 相关切片已存在，但真实 Companion Bridge/MessagePort 外部联调仍受外部插件和环境限制。继续标记为实验/阻塞，不进入核心路径，不把协议测试写成真实服务已接通。

### OW-14 共享空间与关系能力试点

Shared Space、多人权限、协作撤回、审计和删除传播需要独立隐私评审与真实试点；在权限和撤回边界完整前，只保留兼容能力，不升级为默认产品入口。
