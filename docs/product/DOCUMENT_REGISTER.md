## 冲突处理

1. 先检查产品决策记录是否已有 Accepted 决策。
2. 再检查 2026-08-22 重设计包是否有明确裁决。
3. 领域约束服从领域模型和命令契约；界面命名不得反向改变领域语义。
4. 实现档案只报告事实，不得用“代码已存在”覆盖“不做清单”。
5. 无法判断时新增决策记录，不在多个文档里分别写不同答案。
