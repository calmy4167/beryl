# 全站统一导航与页面对齐设计

## 目标

保留 Calmy 的大输入桌面作为首页核心，把现有 app 路由置于一致的导航、页头、侧栏和控件规则下；首页记录入口进入完整记录页。

## 已确认方向

- 首页继续以大输入画布为第一视觉和主要操作。
- 首页右上角提供记录与控制入口；控制打开输入画布的外观选项，系统主题和导航设置保留在统一侧栏入口。
- 首页“记录”入口打开完整记录页：左侧显示全部记录列表并支持按日期回看，选择记录后右侧显示完整原文与已有状态/关联内容。提供“返回首页”回到大输入画布。完整记录页保留原记录状态、业务跳转、安全隐藏和恢复行为；现有“记录”收集处理模块继续保留。
- 模块导航使用统一侧栏/目录；桌面展开时占用固定列、推动内容区重排，窄屏展开时占用内容上方独立区域，不遮挡页面内容。只有点击模块按钮或 Ctrl/⌘+K 才打开；鼠标悬停和焦点变化不触发打开。打开后只有关闭按钮或 Ctrl/⌘+K 收起；切换模块、指针离开、焦点变化和 Esc 都不收起。
- Ctrl/⌘+K 切换模块导航；命令面板从导航中的独立操作打开。滚轮只负责内容滚动，不切换模块。
- 内容页按页面 archetype 保留适合的密度与结构，不把所有业务页面改成同一套卡片布局。

## 公共视觉与交互规则

1. 外层结构统一为品牌/模块导航、当前页面页头、内容区和全局控制入口。
2. 页头统一标题层级、说明文案位置、日期/上下文控件位置以及页级操作按钮排列。
3. 列表-详情、时间线、看板、日历、内容、个人工具、设置和洞察页面分别沿用本类最适合的布局，只共享间距、边框、圆角、状态色、表单和操作控件。
4. 列表和表格继续保留紧凑行结构；编辑器与首页保留宽松画布；统计信息按页面目标决定密度。
5. loading、empty、error、disabled、selected、focus-visible 等状态在所有模块中使用同一套语义规则。
6. 响应式时侧栏收为抽屉或底部导航；弹层内可滚动，底层页面不会被意外滚轮导航打断。

## 边界

- 不改路由、权限、业务数据模型、Repository、同步行为或已有功能。
- 不删除模块，不更改现有记录内容，不将记录隐藏等同于删除。
- 此次视觉对齐不重写各模块的业务交互；发现业务问题时只记录，不顺手改动。
- 继续沿用现有 Liubai 主题 token 和用户已选设置。

## 完成判定

- 首页右上角可打开完整记录页与控制；记录页能浏览全部记录、查看选中详情、返回首页并执行现有记录操作。
- 模块导航在 app 页面共享一套入口、分组和选中状态。
- 滚轮不再用于跨模块跳转；内容区可自然滚动。
- 37 个 app 页面依 archetype 对齐标题、操作、内容密度和状态样式。
