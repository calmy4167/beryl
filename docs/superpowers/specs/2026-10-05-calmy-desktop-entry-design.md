# Calmy 主入口桌面设计

## 背景与目标

将用户提供的 `deepseek_html_20261005_2e794c.html` 作为登录后的系统主入口，迁移其快速记录、回看、快捷键撤销和外观设置交互，并接入 Calmy 当前 Capture、Action 等领域数据。该参考页仅作为产品行为和视觉参考；它自己的 `localStorage` 数据模型不迁入产品。

新入口必须复用已有登录、Vault 解锁、模块导航和模块显示管理。所有模块仍由用户在同一个模块管理器中选择是否显示。首页默认进入安静的空白输入状态；导航通过左侧边缘或快捷键显式唤出，避免持久侧栏挤占主画布。

## 已确认的方案

### 1. 路由与外壳

- 未登录访问根网址时进入 `/login`；已有登录会话访问根网址时进入 `/app/desk`。
- 已登录用户直接访问 `/app` 时也默认进入 `/app/desk`。
- 登录成功后沿用现有 `/vault` 设置/恢复流程；Vault 初始化或恢复完成后进入 `/app/desk`。
- `/app/desk` 要求有效会话且当前设备 Vault 已解锁。未登录时回 `/login`，未解锁时回 `/vault`，首次密码变更仍先走 `/pass`。
- `/app/desk` 使用现有 `LiubaiShell` 的页面区域与模块显示管理器；本页默认隐藏常驻模块侧栏，保留现有导航内容、路由和显隐设置。
- 桌面默认状态为完整宽度的输入画布。左侧边缘保留轻提示区域，指针移入后打开模块导航；键盘快捷键也能打开/关闭导航。导航展开后固定显示，不随指针离开自动关闭；仅点击导航的关闭按钮或再次按快捷键关闭。
- 导航展开时使用侧边抽屉压缩输入画布宽度；关闭后输入画布恢复可用宽度。抽屉仍提供现有模块入口及模块显示管理器，隐藏模块不删除数据或禁用路由。
- 桌面页使用 Ctrl/Cmd+K 开合模块导航；该键在其他页面保持原有“命令面板”行为。命令面板仍可从模块导航中显式打开，避免丢失原有能力。
- 桌面内容需适配 `LiubaiShell` 的 `.stage > .slide > .inner` 页面区域，不能继续用覆盖整个视口的固定层挡住系统外壳控件。
- 当前顶层 `/desk` 保留兼容路由，跳转至 `/app/desk`。
- `/app/today` 及其他模块入口保持可访问；隐藏模块只影响侧栏可见性，不删除数据或禁用其路由。
- 新桌面包含在侧栏模块管理器中，用户隐藏它时，根网址仍会进入桌面，用户也可通过模块管理器重新显示。

### 1.1 完整迁移参考页交互

参考文件完整实现的是一个单页记录工具，而非只有空白首页。除本设计后文已有的快速录入、撤销、历史和外观能力外，还须在 Calmy 中补齐以下交互和表达：

- 编辑区域铺开为桌面主画布；点画布上的空白处聚焦输入；粘贴统一插入纯文本；空白状态显示参考稿的键盘提示。
- 用户编辑时让背景短暂转暖，并在保存、转任务、撤销或收起历史记录后显示短暂状态提示；编辑器自身保持安静，不加表单边框。
- 最近记录采用全屏记录视图，按自然日分组并列出时间；Action 项保留轻量标记；支持空状态、长文本和窄屏滚动。
- 外观设置采用右侧滑入抽屉；点击遮罩或按 Escape 关闭，返回输入画布时恢复输入焦点；保留全部参考档位和本机持久化。
- 每条历史项提供移出桌面最近列表的动作。未处理 Capture 通过现有 `let_go`/归档状态保留历史；已关联业务实体的 Capture 只写入本机桌面隐藏索引，不删除或修改其目标实体。隐藏项可在记录视图中恢复显示。
- 参考 HTML 没有导入/导出、网络请求、账户同步、批量清空或其他页面；不得把它本机 `pms.entries.v1` 演示内容导入 Calmy。

### 2. 快速录入、回看与撤销

- 桌面进入后输入区获得焦点，支持多行文字。
- 普通 Enter 提交非空文字，经现有 `captureText` 用例保存为 Capture。保存成功后清空输入；原文保留在 Capture 中，不创建独立条目库。
- Capture 的建议生成遵循现有 `captureText` 行为。建议失败不回滚或丢弃已经写入的 Capture。
- 在一次提交后 500 毫秒内，于空输入区再次按 Enter，将刚保存的 Capture 经现有 `decideCapture` 决策为当天 Action。若 Capture 写入仍在完成，记录这次升级意图并在拿到 Capture ID 后执行；建议生成不能阻塞该意图。Action 标题取 Capture 原文首行，最多 120 字；空首行使用现有默认标题。日期取当前 `todayKey()`。
- Alt+Enter 和 Shift+Enter 在输入区插入换行；普通 Enter 提交内容。
- Escape 打开最近 Capture 的回看列表，不清除尚未提交的编辑内容。列表按 Capture 更新时间倒序，显示原文、时间与当前状态。已转为 Action 的条目可跳转到“今天”查看；其他条目可跳至相应的现有模块。
- Ctrl/Cmd+Z 在桌面最近一次成功录入或转任务后的 4 秒内撤销该操作；开始输入新草稿或产生另一笔操作时，旧撤销目标失效。编辑未提交文本时，保留输入框自身的编辑撤销行为。
- 撤销新增会移除本次新增的 Capture。撤销转任务会移除本次决策创建的 Action，并把原 Capture 恢复为待处理状态。撤销必须通过应用层用例完成，验证目标仍对应本次操作且没有发生后续修改，避免 UI 直接拼写多个仓库。
- Capture 与 Action 分属不同持久集合，撤销用例需记录可恢复的开始/完成状态并支持幂等重试；只有所有补偿步骤完成后才显示撤销成功。出现中断时保留可恢复状态并阻止同一对象的冲突操作，重试时继续完成补偿；保留可追溯历史。

### 3. 外观设置

桌面右上角提供外观设置入口，面板包含参考页已有选项：

- 背景颜色
- 字号
- 内容栏宽度
- 水平对齐
- 垂直对齐
- 行距
- 字距
- 段落间距
- 恢复默认

选项沿用参考页的档位：字号 14/16/19/22/26px；宽度为全宽、64/48/32rem；水平对齐为左/中/右/两端；垂直位置为上/中/下；行距为 1.5/1.65/1.85/2/2.2；字距为 -0.01/0/0.02/0.05/0.1em；段距为 0/0.5/1/1.5/2em。背景提供参考色板和自定义颜色。默认字号 19px、全宽、左对齐、顶部位置、行距 1.85、字距与段距为 0；默认背景根据系统深浅色偏好在 `#FBFBF8` 和 `#131312` 间选择。

设置存入独立的本机桌面偏好，不与 Capture、Action 等业务数据混用，不承诺跨设备同步。读取或写入偏好失败时安全回退到默认值，并提示设置未能保存。窄屏使用适配移动设备的面板。

### 4. 异常处理与边界

- Capture 写入失败时保留编辑器内容并显示可理解的错误与重试方式。
- Capture 已保存但建议生成失败时清空已提交文本，提示记录已保存、建议暂不可用；用户可以从回看列表继续处理。
- Action 转换失败时保留 Capture 为待处理状态，提示失败并允许重试；不得重复生成 Action。
- 回看列表读取失败时保留桌面录入能力，并显示局部错误和重试入口。
- 触发撤销时若对象已变化或找不到原操作，不执行撤销并明确提示用户刷新状态。若跨集合补偿中途失败，不显示撤销成功；保留可恢复状态并提示用户重试，应用层继续完成剩余补偿。
- 登录态失效继续由路由守卫处理；`/app/desk` 用现有 `hasUnlockedVault` 检查当前用户设备的 Vault 状态，未解锁时先返回 `/vault`，不得加载或显示 Capture/Action 数据。
- 不建立参考稿使用的 `pms.entries.v1` / `pms.prefs.v6` 独立业务存储，不另建认证流程，也不扩展到其他页面的录入行为。

## 验收标准

1. 根网址在未登录、未解锁和已解锁状态下分别遵循现有登录与 Vault 流程；解锁后到达 `/app/desk`。
2. 桌面默认不显示常驻模块侧栏，输入画布占据主区域；左侧边缘悬停或快捷键打开导航后，导航保持展开，直到点击关闭按钮或再次按快捷键关闭。
3. 导航抽屉保留现有模块入口与模块显示管理器；管理模块显隐不会改变任何业务数据，隐藏只影响导航可见性。
4. Enter 新建一条现有 Capture；快速空 Enter 将该 Capture 转为当天 Action，且历史中仍可识别其原始 Capture。
5. Alt+Enter 保留多行录入；Escape 可开关最近记录回看；Ctrl/Cmd+Z 仅撤销最近一笔符合条件的桌面操作。
6. 录入、建议、转换、回看或撤销的局部错误不会清空未保存输入或制造重复实体。
7. 所有参考页外观偏好均可调整、持久化于本机、恢复默认，并适配窄屏。

## 范围与后续实现提示

本设计只确定系统主入口桌面及其必要的数据操作边界。实现计划应先检查登录后 Vault 跳转、路由守卫、模块清单/模块管理器与 Capture/Action 命令模型的当前行为，再拆分路由外壳、桌面交互、撤销用例和偏好设置工作。桌面路由注册到模块清单时，保持已有模块分类和用户显隐设置兼容。
