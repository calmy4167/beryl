# Calmy 双层导航与工作区 Tab 设计

日期：2026-09-21  
状态：用户已在视觉方案页选择方案 A  
视觉依据：用户提供的 LIMS 页面截图，仅借鉴壳层界面语言，不复制产品结构、业务模块或表格内容。

## 1. 目标

把 Calmy 现有桌面壳层调整为“一级图标轨道 + 二级页面侧栏 + 顶部工作区 Tab”，让功能入口与正在处理的页面分工明确：

- 左侧一级轨道回答“去哪个功能组”；
- 左侧二级侧栏回答“打开组内哪个现有页面”；
- 顶部工作区 Tab 回答“回到哪个已经打开的页面”；
- 中央页面继续渲染现有路由与真实数据。

## 2. 不改变的内容

- `route-manifest.ts` 中现有页面、路径、标题、功能组与排序保持不变。
- Today、记录、处境、回顾仍是原有四个主入口；界面只在一级轨道中把它们显示为“日常”组。
- 不修改页面组件的领域行为、Repository、IndexedDB、同步、认证、保存协议或路由语义。
- 移动端继续使用现有顶栏、底部四入口和功能抽屉，不强行塞入桌面 Tab。

## 3. 桌面结构

```text
DesktopShell
├── PrimaryRail (固定 68px)
│   ├── Brand
│   ├── 日常
│   ├── 工作 / 内容 / 关系 / 工具 / 试验 / 个人
│   └── 收起与设置
├── SecondarySidebar (展开时 128–252px，可随现有分隔线调整)
│   ├── 当前组标题
│   ├── 当前组现有页面列表
│   └── 搜索 / 全部功能
├── Workspace
│   ├── GlobalTopBar
│   ├── WorkspaceTabs
│   └── RoutedPage
└── ContextRail
```

现有左栏宽度偏好继续代表一级轨道和二级侧栏的总宽度。收起时只保留一级轨道；分隔线只在展开时可拖动。折叠按钮必须完整留在轨道内，不能越界裁切。

## 4. 一级轨道与二级侧栏

- 一级轨道使用一个连续移动的 active track，切组时不闪烁。
- “日常”是现有四个主入口的视觉容器，不改变它们的导航等级或路由。
- 其他六组直接来自 `featureNavigationGroups`；组名、页面名、路径与顺序不另建一份配置。
- 当前路由所在组默认打开；用户可只切换查看其他组，不会在未选择具体页面前改变路由。
- 二级侧栏中的当前路由使用 `aria-current="page"`；轨道按钮使用 `aria-pressed` 表达当前查看组。
- “搜索”和“全部功能”保留，全部功能仍使用当前键盘可操作的浮层/移动抽屉。

## 5. 工作区 Tab

- “今天”是固定 Tab，始终存在且不可关闭。
- 访问桌面应用路由时创建或激活对应 Tab；同一路径只保留一个。
- 点击 Tab 使用现有路由导航，不缓存或复制页面业务状态。
- 关闭非活动 Tab 只移除该 Tab；关闭活动 Tab 后进入其左侧相邻 Tab，若不存在则回到“今天”。
- 每个浏览器会话最多保留 12 个 Tab；超过时移除最早打开的非固定、非活动 Tab。
- Tab 顺序保存在 `sessionStorage`，不进入业务数据、同步或跨设备设置。
- Tab 条可水平滚动；活动 Tab 自动进入可视区域；固定 Tab 具有固定标识，其他 Tab 有关闭按钮。
- 当前页面处于保存中、等待持久化、冲突或失败状态时，只在活动 Tab 上显示状态点；不把它误写成业务上的“未完成”。

## 6. 视觉规则

- 一级轨道使用午夜蓝稳定结构，二级侧栏使用白色表面，工作区 Tab 位于冷灰过渡层。
- 活动 Tab 与页面白色工作面连成一体，顶部用 2px 电光蓝标记，不使用大面积高饱和填充。
- 非活动 Tab 使用浅灰底和细边框；关闭按钮仅在 hover、focus 或活动态增强。
- 侧栏与 Tab 均采用 6–8px 小圆角，分隔线连续，避免每个区域独立成卡片造成割裂。
- `prefers-reduced-motion` 下取消 track 位移与自动滚动动画，但保留选中颜色、边界和文本状态。

## 7. 响应式

- `> 1180px`：显示双层侧栏、工作区 Tab 和右侧情境栏。
- `901–1180px`：显示双层侧栏和 Tab；右侧情境栏继续按现有规则隐藏或转为抽屉。
- `≤ 900px`：不显示桌面侧栏、桌面 Tab 和拖动分隔线，沿用移动壳层。

## 8. 验收

- 所有现有 app 路由仍可通过侧栏或全部功能到达，路径与页面组件不变。
- 一级轨道只有一个 active track，二级侧栏准确显示当前组页面。
- 今天 Tab 不可关闭；其他 Tab 可激活、关闭、去重、限量并在会话内恢复。
- 左侧和右侧分隔线仍可鼠标拖动、键盘调整并保存宽度。
- 1440px 桌面无水平页面溢出；折叠按钮、Tab 关闭按钮和溢出滚动均可见可操作。
- 定向测试、现有可访问性测试、全量测试和构建通过；既存失败单独报告。
