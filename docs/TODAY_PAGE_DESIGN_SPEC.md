# 「今天」页设计规格（依据 `tmp/design/today-design-combo.png`）

> 交付对象：实现方 AI。本文件是该图的**完整文字描述**，不依赖看图即可实现。
> 参考实现已经落地在 `src/vue/pages/LiubaiToday.vue`（Vue 3 `<script setup>` + scoped CSS），可直接对照。
> 画布：1500 × 1120 px（桌面），浅色主题（paper），**含外壳顶部的 `显示/主题` 控件与左侧玻璃导航条，
> 但那两部分不属于本页**，本规格只描述页面主体。

---

## 1. 整页骨架

```
┌ 头部一行 ────────────────────────────────────────────────────────────────┐
│ 今天  周二 · 10月13日                            [ 今天 ▾ ]  [ ✓ 复盘今日 ] │
└──────────────────────────────────────────────────────────────────────────┘
┌ 指标条（一张卡，4 等分）──────────────────────────────────────────────────┐
│ 计划 6 项 │ 已完成 2 项 │ 今日专注 2 小时 40 分 │ 重点 2 项                │
└──────────────────────────────────────────────────────────────────────────┘
┌ 通栏快速添加 ────────────────────────────────────────────────────────────┐
│ [ 添加今天要做的事…                                          ]      [ + ]  │
└──────────────────────────────────────────────────────────────────────────┘
┌ 左列（1.7fr）────────────────────────────┐ ┌ 右列（1fr）───────────────┐
│ 今日计划                    ≡ 重点优先 ▾ │ │ 当日数据              ›    │
│  • 行 / 行 / 行 / …                      │ │  ◯ 33% 完成率 / 待办 …    │
│  已完成 2 项 · …                          │ ├──────────────────────────┤
├──────────────────────────────────────────┤ │ 习惯打卡              ›    │
│ 今日时间线                            ›   │ │ 晨间拉伸 ●●●○○○○  打卡    │
│  ● 09:40 专注 52 分钟            专注     │ ├──────────────────────────┤
│  ○ 09:12 和产品确认今日范围      记录     │ │ 收集箱                ›    │
└──────────────────────────────────────────┘ │ 全部 4 条 →               │
                                              └──────────────────────────┘
```

**页面容器**：`max-width: 1180px`，水平居中；纵向 `flex column`，块间距 **18px**。
**两列网格**：`grid-template-columns: minmax(0, 1.7fr) minmax(0, 1fr); gap: 18px; align-items: start`。

## 2. 设计令牌（浅色 / paper 主题）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | 浅蓝到白的**极光渐变**（多组柔和径向光斑叠在 `#dce9f7 → #f3f5f8 → #e6edf5` 之上） | 页面底 |
| `--panel` | `#ffffff` | 输入框、药丸按钮、小 chip |
| `--panel-2` | `#f7f9fc` | **所有卡片**底色（含指标条） |
| `--line` | `#e4e8ef` | 分隔线、环形轨道 |
| `--line-strong` | `#cbd3df` | 未点亮的小圆点、日期点 |
| `--fg` | `#111827` | 主文字 |
| `--muted` | `#667085` | 次要文字、标签 |
| `--accent` | `#0a6cff` | 主按钮、进度环、重点圆点、时间线强调点 |
| `--accent-fg` | `#ffffff` | 主按钮文字 |
| `--hover` | `#f1f5fb` | 悬停底 |
| `--cta` | `color-mix(in srgb, var(--accent) 68%, var(--muted))` | **动作文字**（完成 / 打卡 / 去处理），比 accent 更收敛 |

**阴影只用一处**：`0 1px 2px rgba(16, 24, 40, .04)`（4%，几乎不可见）。**卡片无描边**，层次靠 `--panel-2` 与底色的差异。
**间距一律 4px 倍数**：6 / 8 / 10 / 12 / 16 / 18 / 20 px。

## 3. 逐块规格

### 3.1 头部（一行，`align-items: center`，两端对齐）

| 元素 | 规格 |
|---|---|
| `今天` | 字号 **1.9rem**，字重 **700**，字距 `-.04em`，色 `--fg` |
| `周二 · 10月13日` | 字号 **.92rem**，色 `--muted`；与标题同基线，间距 **12px** |
| `今天 ▾` 药丸 | 白底 `--panel`，高 **38px**，内边距 `0 12px`，圆角 **10px**，`1px --line` 描边；文字 .86rem/500，右侧 `▾` 用小一号（.6em）灰色 |
| `✓ 复盘今日` | **主按钮**：`--accent` 实底、文字 `--accent-fg`，高 **38px**，内边距 `0 16px`，圆角 **10px**，字号 .86rem/600，`✓` 与文字间距 7px；hover `brightness(1.06)` |

右侧两件控件整体与标题行同一直线；间距 10px。

### 3.2 指标条（一张卡，4 等分）

- 容器：`--panel-2` 底，圆角 **14px**，4% 阴影，`overflow: hidden`，`grid-template-columns: repeat(4, minmax(0,1fr))`
- 单元格：`padding: 16px 20px`，纵向排列 —— **标签在上，数值在下**
  - 标签：.8rem，`--muted`
  - 数值：**1.5rem / 字重 650 / 字距 -.03em / `font-variant-numeric: tabular-nums`**；单位用 `<small>`（.85rem / 500）紧贴数字
- 分隔：除第一格外，每格左侧 `1px solid color-mix(in srgb, var(--line) 75%, transparent)`
- 四格固定语义与顺序：**计划 · 已完成 · 今日专注 · 重点**
  - `计划 6 项`｜`已完成 2 项`｜`今日专注 2 小时 40 分`（小时为 0 时只显示分钟）｜`重点 2 项`

### 3.3 通栏快速添加

- 一行 `flex`，间距 10px
- 输入框：`flex: 1`，高 **46px**，圆角 **12px**，白底 `--panel`，4% 阴影，**无描边**，内边距 `0 16px`，字号 .95rem；
  占位文字 `添加今天要做的事…`（`--muted`）；聚焦时 `box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent) 16%, transparent)`
- 提交按钮：**52 × 46px**，`--accent` 实底，白色 `+`（1.3rem / 行高 1），圆角 **12px**；
  输入为空或保存中时 `opacity: .45` 且不可点；hover `brightness(1.06)`
- （实现补充）可在此行右侧加一个「不关联处境」下拉（宽 170px / 高 46px / 同样式），用于把新行动关联到处境

### 3.4 卡片通用样式（今日计划 / 今日时间线 / 当日数据 / 习惯打卡 / 收集箱）

```
background: var(--panel-2);
border-radius: 14px;
box-shadow: 0 1px 2px rgba(16, 24, 40, .04);
padding: 18px 20px;
display: flex; flex-direction: column; gap: 12px;
```
卡头一行：左标题 **1.06rem / 650 / 字距 -.02em / `--fg`**；右侧为「排序按钮」「`›` 箭头」或「全部 N 条 →」。

### 3.5 今日计划（左列上）

- 卡头右侧：`≡ 重点优先 ▾` —— 高 32px，圆角 9px，白底 `--panel`，字号 .82rem，`--muted`；**点击切换排序**（`重点优先 ⇄ 按状态`）
- 列表行（每行 `padding: 12px 0`，行间 `1px color-mix(in srgb, var(--line) 80%, transparent)`，首行无分隔线）：
  - **行前圆点**：6px 圆，默认 `--line-strong`；**重点行** 放大到 ~8px 且用 `--accent`
  - **标题**：.95rem / 500 / `--fg`，单行省略；**重点行** 提到 650；点击标题 = 设/取消「今日重点」
  - **处境标签**（可选）：`padding: 2px 8px`，圆角 6px，底 `color-mix(in srgb, var(--accent) 9%, var(--panel))`，字 `color-mix(in srgb, var(--accent) 82%, var(--fg))`，.72rem
  - **进行中标记**（可选）：标题后追加「进行中」小签，底 `color-mix(in srgb, #f59e0b 18%, transparent)`，字 `color-mix(in srgb, #f59e0b 78%, var(--fg))`
  - **右端动作**：文字按钮「完成」—— **`--cta` 色**，.78rem，圆角 7px，hover 底 `color-mix(in srgb, var(--accent) 10%, transparent)`
- 列表下方：`已完成 2 项 · 完成首页模块布局优化、整理本周需求与待办`（.78rem / `--muted`，上方 1px 分隔线，`padding-top: 10px`，单行省略）
- 超过 6 条时，在列表与已完成行之间加一行 `.78rem --muted`：`还有 N 件未显示`

### 3.6 今日时间线（左列下）

- 卡头右侧：`›`（`--muted`，1.1rem）
- 纵向时间轴：左侧 **1px `--line` 竖线**（定位 `left: 4px`；**首条**从 50% 起、**末条**到 50% 止）
- 每行 `padding: 9px 0 9px 20px`，`align-items: baseline`：
  - **圆点**：9px 圆（含 2px 描边），默认描边 `--line-strong` + 底 `--panel-2`；**专注行**：描边与底都是 `--accent`
  - **时间**：固定宽 `3.6em`，.8rem，`--muted`，等宽数字
  - **文案**：.88rem / 500 / `--fg`，单行省略
  - **类型标签**：`记录 / 专注 / 完成`，`padding: 1px 7px`，圆角 6px，底 `--panel`、字 `--muted`；**专注** 用 `color-mix(in srgb, var(--accent) 12%, transparent)` 底
- 排序：按时间**升序**，最多 6 条

### 3.7 当日数据（右列上）

- 卡头右侧 `›`
- 内容：左 **进度环** + 右 **四行事实**
  - 进度环：SVG 118 × 118，`r=50`，`stroke-width: 9`，圆头；轨道 `--line`；进度 `--accent`，`transform: rotate(-90deg)`；
    `stroke-dasharray: 314`，`stroke-dashoffset: 314 × (1 − 完成率)`；变化时 `.4s` 过渡
  - 事实行（每行 `padding: 9px 0`，行间 1px `color-mix(--line 80%, transparent)`）：左标签 .8rem `--muted`，右数值 .9rem/600 `--fg` + 等宽数字
  - 四行固定：**完成率 33% ｜ 待办 3 件 ｜ 习惯打卡 1/2 ｜ 收集箱 4 条**

### 3.8 习惯打卡（右列中）

- 卡头右侧 `›`
- 每个习惯一行（`padding: 9px 0`，行间 1px 分隔）：
  - 名称：.9rem / 500 / `--fg`，`flex: 1`，单行省略
  - **本周点阵**：7 个 6px 圆点，间距 3px；已打卡 `--accent`，未打卡 `--line-strong`
  - **打卡按钮**：文字按钮，`--cta` 色，.74rem，圆角 8px；**已打卡**时显示「已打卡」并转 `--muted`
- 无习惯时：一行 `--muted` 空态「还没有习惯。」

### 3.9 收集箱（右列下）

- 卡头右侧：`全部 4 条 →`（`--cta`，.78rem；点击进入记录/收集页）
- 最多 2 条原文，每条 `padding: 8px 0`，行间 1px 分隔，.9rem / `--fg`，单行省略
- 无内容时：`--muted` 空态「没有待归类的原文。」

## 4. 交互与状态

| 对象 | 状态 |
|---|---|
| 计划行标题 | 默认 500；**重点** 650 + 大号 accent 圆点；点击切换重点（`aria-pressed`） |
| 计划行「完成」 | hover 出现 accent 10% 底；点击后该行移入「已完成 N 项」汇总 |
| 排序按钮 | 在 `重点优先`（重点在前，其余按创建时间）与 `按状态`（进行中在前）之间切换，按钮文案同步 |
| 新行动输入 | 空 → `+` 按钮 45% 透明度禁用；有内容 → 可点/回车提交；提交后清空 |
| 习惯打卡 | 点击写入当天打卡；已打卡状态按钮转灰 |
| 进度环 | 完成率变化时 `stroke-dashoffset` 过渡 0.4s |
| 空态 | **每个卡片各自给一句可操作的空态文案**，不留整片空白 |

**响应式**：`max-width: 1080px` 时两列变单列；指标条变 2×2（第 1、2 格去掉上分隔线，奇数列去掉左分隔线）；添加行换行，处境下拉占满一行。

## 5. 数据映射（实现方不要自造字段）

| 展示项 | 取数 |
|---|---|
| 计划 N 项 | 当天行动总数 |
| 已完成 N 项 | 当天 `status === 'done'` 的行动数 |
| 今日专注 X 小时 Y 分 | 当天"专注"记录（正文以 `[番茄钟]` 开头、含 `N 分钟`）的分钟数求和；小时为 0 时只显示分钟 |
| 重点 N 项 | 当天计划的 `focusActionIds.length` |
| 计划行 | 当天未结束（非 done/cancelled/skipped）的行动；`重点优先` = 重点在前、其余按创建时间；`按状态` = 进行中在前 |
| 行动标签 | 行动关联的**处境**名称（`matterId`） |
| 时间线 | 当天记录（`occurredAt`，专注记录显示为「专注 N 分钟」）+ 当天已完成行动（用其 `updatedAt` 作为完成时刻），按时间升序取最近 6 条 |
| 完成率 | 已完成 ÷ 行动总数（总数为 0 时显示 0%） |
| 待办 | 当天未结束行动数 |
| 习惯打卡 x/y | 当天已打卡习惯数 / 习惯总数；点阵 = 本周 7 天 |
| 收集箱 | 待归类原文条数 + 最近 2 条正文 |
| 复盘按钮 | 当天复盘已填写 → 文案变「今日已复盘」 |

**参考图里有、但本项目没有数据源的字段，一律不要实现**：剩余估算时长、计划时刻表与单项时长、
优先级、每日专注目标（"2h40m / 6h"）、"连续专注 / 休息次数"。规格里已用真实字段替代，见上表。

## 6. 一句话给实现 AI 的提示词

> 用 Vue 3 `<script setup>` + scoped CSS 实现一个"今天"页：顶部一行（大标题 `今天` + 日期 + 右侧「今天 ▾」药丸与
> `✓ 复盘今日` 主按钮）；下方一张四等分指标条卡（计划 / 已完成 / 今日专注 / 重点）；再下方通栏输入 + 方形 `+` 按钮；
> 主体为 1.7fr / 1fr 双列：左列两张卡（今日计划：可勾完成的行 + 重点优先排序 + 已完成汇总；今日时间线：竖向时间轴 + 时间/文案/类型标签），
> 右列三张卡（当日数据：118px 进度环 + 四行事实；习惯打卡：名称 + 7 点阵 + 打卡；收集箱：两条原文 + 全部入口）。
> 卡片统一 `--panel-2` 底、14px 圆角、`0 1px 2px rgba(16,24,40,.04)` 阴影、无描边、内边距 `18px 20px`；块间距 18px；
> 强调色 `#0a6cff`，动作文字用更柔和的蓝；所有数字用等宽数字；空态给可操作文案；≤1080px 变单列。
